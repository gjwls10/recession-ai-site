# 한국 경기침체 확률 사이트

선행종합지수의 하강 신호를 기준으로, 입력 지표 6종(실질 GDP, 산업생산, 소매판매, 소비자물가, 장단기금리차, 제조업 업황전망 BSI)으로 현재와 3·6·12개월 후 침체 신호 확률을 추정해 보여 주는 정적 사이트입니다.

- 사이트: https://gjwls10.github.io/recession-ai-site/
- 데이터: 한국은행 ECOS, 통계청 KOSIS
- 김포제일고 2026학년도 이공계 프로젝트학습 (팀 일단 해)

## 페이지

| 페이지 | 내용 |
|---|---|
| 대시보드 (`index.html`) | 현재·3·6·12개월 후 침체 신호 확률, 경고 단계, 이번 달 요약, 확률 추이 |
| 원인 분석 (`drivers.html`) | 변수별 기여도, 전월 대비 변화, 부문별 기여도 추이 |

| 방법론 (`about.html`) | 데이터, 타깃 정의, 모형, 검증 방법 |
